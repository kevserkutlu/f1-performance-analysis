# Formula 1 Race Performance Analysis and Result Prediction 🏎️

Ankara Medipol University - Computer Engineering / Design and Analysis of Algorithms Project.

## Project Objective
[cite_start]This project focuses on the analysis of historical Formula 1 race data to gain deeper insights into the performances of drivers and teams and to develop predictive models for race outcomes using Machine Learning. [cite: 8, 11]
